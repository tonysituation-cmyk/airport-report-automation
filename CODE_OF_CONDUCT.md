# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

In short: be kind, be respectful, and treat everyone as a collaborator.
Harassment, personal attacks, and discriminatory behaviour of any kind are
not tolerated in issues, pull requests, discussions, or any other project space.

Report conduct concerns to the project maintainer via the email in the README.
Maintainers will review and investigate all complaints and respond
appropriately, and may remove, edit, or reject contributions that violate
this code.
